# {変数|へんすう}ってなに？

:::sensei
今日は「{変数|へんすう}」を学ぶよ。
{変数|へんすう}は、ものを入れておく{宝箱|たからばこ}みたいなものだよ！
:::

:::student
{宝箱|たからばこ}！？
なにを入れるの？
:::

:::sensei
{数字|すうじ}や{言葉|ことば}を入れられるんだ。
しかも、好きな名前をつけられるよ！
:::

## {宝箱|たからばこ}に名前をつけよう

{変数|へんすう}を作るのはかんたん。
`=` を使って、箱に中身を入れるだけ！

```python runnable
takara = "ダイヤモンド"
print(takara)
```

`takara` という名前の箱に、`"ダイヤモンド"` を入れたよ。
`print()` で箱の中身を見ることができるんだ。

:::hint
`=` は「同じ」という{意味|いみ}じゃないよ。
「右のものを、左の箱に入れる」という{意味|いみ}だよ！
:::

## いろんなものを入れてみよう

{宝箱|たからばこ}には、いろんなものを入れられるよ。

```python runnable
# 動物の名前（文字）
doubutsu = "ネコ"
print(doubutsu)

# 年齢（数字）
nenrei = 10
print(nenrei)

# 好きな食べ物（文字）
tabemono = "カレーライス"
print(tabemono)
```

:::sensei
`#` のあとに書いた{文字|もじ}は「コメント」といって、
プログラムには{影響|えいきょう}しないメモだよ。
自分用のメモを書いておくと便利だね！
:::

## 箱の中身を使おう

:::student
箱に入れたものって、どうやって使うの？
:::

:::sensei
箱の名前を書くだけで、中身を使えるよ！
:::

```python runnable
namae = "タロウ"
nenrei = 10

print("ぼくの名前は" + namae + "です")
print(f"ぼくは {nenrei} さいです")
```

`f"..."` と書くと、`{}` の中に{変数|へんすう}を入れられるよ。
これを「f-string（エフストリング）」っていうんだ。

## 箱の中身を変えよう

:::sensei
{宝箱|たからばこ}の中身は、あとから変えられるよ！
:::

```python runnable
okashi = "チョコレート"
print(f"今のおかし: {okashi}")

okashi = "グミ"
print(f"変えたあと: {okashi}")
```

同じ箱に、新しいものを入れると中身が変わるんだ。
前に入っていたものは消えちゃうから気をつけてね！

## {数字|すうじ}と{文字|もじ}

:::student
{数字|すうじ}と{文字|もじ}って、何がちがうの？
:::

:::sensei
{数字|すうじ}は{計算|けいさん}ができるけど、
{文字|もじ}は{計算|けいさん}できないんだ。
{文字|もじ}は `"` で囲むのがルールだよ！
:::

```python runnable
# 数字は計算できる
kazu = 5
print(kazu + 3)

# 文字は「くっつける」ことができる
moji = "ニャー"
print(moji + moji + moji)
```

:::hint
`"5"` と `5` はちがうよ！
`"5"` は{文字|もじ}で、`5` は{数字|すうじ}だよ。
`"` があるかないかで見分けよう！
:::

## やってみよう

自分の{情報|じょうほう}を{変数|へんすう}に入れて、
{表示|ひょうじ}してみよう！

```python runnable
namae = "サクラ"
nenrei = 9
suki = "アイスクリーム"

print(f"名前: {namae}")
print(f"年齢: {nenrei}さい")
print(f"好きな食べ物: {suki}")
```

:::sensei
名前や{年齢|ねんれい}を自分のものに変えてみよう！
コードを変えて{実行|じっこう}してみてね。
:::

## まとめ

- {変数|へんすう}は、ものを入れる{宝箱|たからばこ}
- `=` で箱に中身を入れる（{代入|だいにゅう}）
- `print()` で中身を{表示|ひょうじ}できる
- 箱の中身はあとから変えられる
- {数字|すうじ}と{文字|もじ}（`"` で囲む）がある
